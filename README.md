# Financely-Frontend
This is the repo for the user-interface of Financely personal finance management system.
It allows users to manage their income, expenses, and budgets with the help of a web interface
This application is built with react and communicates with a backend API. It features includes:
User Authentication, Dashboard for financial summaries, Budget Management, Financial Insights and Analytics,  Responsive design for desktop and mobile devices.
The Tech Stack includes: React, Javascript, HTML5, CSS3, REST API integration
